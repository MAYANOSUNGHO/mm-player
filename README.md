# MM Player

저장소: https://github.com/MAYANOSUNGHO/mm-player

실제 영상 파일은 그 자리에 두고, 프로그램 안에서만 폴더와 태그로 정리하는 Windows용 영상 플레이어입니다.

이 프로그램은 AI의 도움을 받아 제작했습니다.

영상 목록, 가상 폴더, 태그, 재생목록, 썸네일은 이 저장소에 없습니다. 그 데이터는 각 컴퓨터의 `%APPDATA%\video-organizer`에만 저장됩니다.

## 주요 기능

### 라이브러리

폴더를 하나 고르면 그 아래 폴더까지 영상을 찾습니다. 지원하는 형식은 mp4, mkv, avi, mov, wmv, webm, m4v, flv, ts 등입니다. 스캔은 목록만 만들고 파일을 옮기거나 복사하지 않습니다.

왼쪽에서 전체 영상, 미분류, 가상 폴더, 태그를 오갈 수 있습니다. 위쪽에서는 이름, 날짜, 크기, 길이로 정렬하고 칸 크기를 바꿀 수 있습니다. 검색은 제목, `#태그`, 경로를 함께 봅니다.

### 가상 폴더

가상 폴더는 디스크에 만들어지지 않습니다. 영상을 끌어다 놓아 분류하고, 폴더 안에 하위 폴더를 만들 수 있습니다.

**하위폴더까지 보기**를 켜면 상위 폴더에서 그 아래 폴더의 영상까지 같이 보입니다. 끄면 그 폴더에 직접 넣은 영상만 보입니다.

### 태그와 재생목록

영상에 태그를 여러 개 붙일 수 있습니다. 재생목록은 순서를 가진 묶음이고, 재생목록 재생으로 이어서 볼 수 있습니다.

### 재생

카드를 두 번 누르면 프로그램 안에서 재생합니다. 재생 중 왼쪽, 오른쪽 화살표는 5초씩 이동합니다. 기본 플레이어로 열기와 탐색기에서 위치 표시도 됩니다.

카드 위에 마우스를 올리면 짧게 미리보기가 재생됩니다.

### 썸네일

영상 카드는 썸네일을 만들어 보여 줍니다. 썸네일이 비어 있는 영상이 있으면, 그 가상 폴더를 연 뒤 **썸네일 재설정**을 누릅니다. 지금 보고 있는 폴더의 영상만 다시 만들고, 라이브러리 전체를 다시 만들지는 않습니다. 하위폴더까지 보기가 켜져 있으면 그때 화면에 포함된 영상도 같이 다시 만듭니다.

### 없어진 파일

원래 경로에 파일이 없으면, 설정해 둔 폴더 아래에서 같은 이름의 영상을 찾아 경로를 다시 연결합니다. 같은 이름이 여러 개면 용량이 같은 파일을 고릅니다.

그래도 찾지 못하면 썸네일에 ×가 나옵니다. 그 카드를 누르면 파일 선택 창이 열리고, 직접 경로를 지정할 수 있습니다. 가상 폴더와 태그는 그대로 남습니다.

### 선택

빈 곳을 드래그하면 범위 안의 영상이 선택됩니다. Shift를 누른 채 드래그하면 이미 선택한 영상에 더해집니다. Shift를 누른 채 클릭하면 처음 고른 카드부터 그 카드까지 범위로 선택됩니다.

### 삭제

영상을 우클릭하고 **삭제**를 누르면 두 가지 중 하나를 고릅니다.

- **목록에서만 제거**는 원본 파일을 그대로 둡니다. 다시 스캔해도 목록에 돌아오지 않습니다. 다시 넣으려면 그 영상 파일을 프로그램 창으로 끌어다 놓습니다. 가상 폴더를 연 상태에서 놓으면 그 폴더에 들어갑니다.
- **원본 파일 삭제**는 파일을 Windows 휴지통으로 보냅니다.

여러 장을 선택한 뒤 그중 하나를 우클릭하면 선택된 영상이 함께 대상이 됩니다.

## 실행

설치본은 GitHub Releases의 `MM-Player-Setup` 실행 파일입니다. 설치한 뒤 시작 메뉴나 바탕화면의 MM Player로 엽니다.

개발 중에는 프로젝트 폴더에서 `npm install` 후 `npm run dev`로 실행할 수 있습니다. `release\win-unpacked\MM Player.exe`는 그 폴더 안의 파일과 같이 있어야 실행됩니다.

## 업데이트

프로그램을 실행할 때마다 GitHub의 최신 릴리스를 확인합니다. 지금 버전보다 새 릴리스가 있으면 **업데이트 하시겠습니까?** 창이 열리고, 그 릴리스에 적어 둔 변경 내용이 그대로 표시됩니다.

- **네**를 누르면 설치 파일을 받은 뒤 설치 프로그램을 실행하고, 지금 켜 둔 프로그램은 닫힙니다.
- **다음에**를 누르면 이번 실행에서는 넘어갑니다. 다음에 프로그램을 켤 때 아직 그 버전이 최신이면 다시 묻습니다.

릴리스가 없거나 인터넷에 연결되지 않으면 창을 띄우지 않습니다.

### 새 버전을 올리는 방법

기능을 바꾼 뒤 사용자에게 업데이트를 알리려면 버전을 올리고, 변경 내용을 태그 메모에 적은 다음 그 태그를 GitHub에 푸시합니다. GitHub Actions가 Windows 설치 파일을 만들고, 태그 메모를 릴리스 설명으로 올립니다. 프로그램은 그 설명을 업데이트 창에 가져옵니다.

```powershell
# package.json 의 version 을 새 번호로 바춘 다음
git add -A
git commit -m "재생 중 구간 반복을 넣는다"
git tag -a v1.1.0 -m "재생 중 구간 반복을 넣었습니다.`n가상 폴더 순서를 바꿀 수 있습니다."
git push origin main
git push origin v1.1.0
```

`package.json`의 `version`과 태그 번호는 같아야 합니다. 태그는 `v1.1.0`처럼 `v`로 시작합니다. 태그 메모의 줄이 업데이트 창의 변경 내용이 됩니다.
